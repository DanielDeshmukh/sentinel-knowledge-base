# NIST Cybersecurity Framework 2.0: Overview

## Purpose

The NIST Cybersecurity Framework 2.0 is a voluntary guide for understanding, assessing, prioritizing, and communicating cybersecurity risk. It describes high-level outcomes; it does not prescribe one mandatory set of controls or a single implementation sequence.

## Six Functions

- **Govern:** Establish cybersecurity risk-management direction, responsibilities, and oversight.
- **Identify:** Understand assets, context, dependencies, and risks.
- **Protect:** Apply safeguards to reduce cybersecurity risk.
- **Detect:** Find and analyze potential cybersecurity events.
- **Respond:** Take coordinated action when an incident occurs.
- **Recover:** Restore services and improve resilience after an incident.

Organizations can use Profiles to describe current and desired outcomes and Tiers to characterize the rigor of risk-management practices. These tools support planning; they are not certifications by themselves.
