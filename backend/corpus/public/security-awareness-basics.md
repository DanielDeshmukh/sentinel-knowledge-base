# Practical Security Awareness Basics

## Everyday actions

CISA's public awareness guidance recommends a small set of habits that reduce common account and device risks:

- Pause before interacting with unexpected messages; avoid and report suspected phishing.
- Use long, unique passwords and a password manager.
- Turn on multifactor authentication for important accounts.
- Install software and security updates promptly.

## For organizations

Organizations should make it easy to report suspicious activity, keep important data recoverable with tested backups, protect sensitive information, and maintain an incident-response plan that people can use. Awareness guidance complements technical controls; it does not replace them.
